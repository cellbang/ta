# Ta

[中文](README.md)

Ta is a double of you, an AI that codes and works for you in the terminal, on your computer and on your phone, and remembers you.

This repository is for **feedback** and **releases**; the source is not here.

## Feedback

- Something wrong: [report a bug](https://github.com/cellbang/ta/issues/new?template=bug.yml). `/bug` in Ta, or Help › Report an Issue in the desktop app, fills in the version and the platform.
- Something you want: [suggest it](https://github.com/cellbang/ta/issues/new?template=feature.yml).
- [Search](https://github.com/cellbang/ta/issues) first: if someone asked already, a 👍 is enough.

Please keep keys, tokens and private conversations out of issues.

## Install

```bash
npm i -g @celljs/ta     # Node.js >= 22.19
ta                      # in the terminal
ta serve                # in the browser
```

The desktop app checks for updates by itself: Ta › Check for Updates… says which version and channel (release or development builds) it is.
