# Ta

[English](README.en.md)

Ta 是一个 AI 分身：在终端、电脑、手机上替你写代码、干活，并且记得你。

这个仓库用来**收集反馈**和**发布版本**，源码不在这里。

## 反馈

- 遇到问题：[提交 Bug](https://github.com/cellbang/ta/issues/new?template=bug.yml)。在 Ta 里输入 `/bug`，或者在桌面版的「帮助 › 反馈问题」，会自动带上版本和平台信息。
- 想要什么：[提建议](https://github.com/cellbang/ta/issues/new?template=feature.yml)。
- 提交前先[搜一下](https://github.com/cellbang/ta/issues)有没有人提过，有的话点个 👍 就好。

请不要在 issue 里贴密钥、token 或者私人对话内容。

## 下载

**[download.cellbang.com/ta](https://download.cellbang.com/ta)**：macOS（Apple 芯片）。下载后解压，把 Ta 拖进「应用程序」，以后它会自己更新。

终端里用：

```bash
npm i -g @celljs/ta     # Node.js >= 22.19
ta                      # 终端里用
ta serve                # 在浏览器里用
```

桌面版会自己检查更新：装好后在「Ta › 检查更新…」里能看到当前版本和通道（正式版或开发版）。

## 版本

每个版本的更新内容见 [Releases](https://github.com/cellbang/ta/releases)。
