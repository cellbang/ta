## Patch Changes

- A conversation in a directory whose AGENTS.md names the mark of a role no longer loses its tools. The extensions looked for the marks of roles (`[ta-moments:answers]`, `[ta-rooms:double]`, `<ta-cron-run>`, `[ta:speaks-with-others]`, the agents of channels, ask before handing out work) in the whole system prompt, which holds the context files too; the AGENTS.md of this repository named the mark of Moments' answers, so every conversation here took all its tools away and an external agent's calls failed with "Tool agent_tool not found". They now look in the role alone, the `<addendum>` section pi puts it in (`TaHostUtil.marked`). (`@celljs/ta-channels`, `@celljs/ta-cron`, `@celljs/ta-initiative`, `@celljs/ta-moments`, `@celljs/ta-nearby`, `@celljs/ta-protocol`, `@celljs/ta-recall`, `@celljs/ta-rooms`)
