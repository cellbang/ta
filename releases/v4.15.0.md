## Minor Changes

- Ta speaks Traditional Chinese and Japanese besides Simplified Chinese and English: the web page, the desktop app, the built-in extensions, the pages of the relay and what ta serve says. Settings, Language lists the four; following the system, Taiwan, Hong Kong and Macau get Traditional Chinese. `TaLanguage` and `TaLanguageUtil` of ta-protocol pick the words of a language. (`@celljs/ta-agents`, `@celljs/ta-bots`, `@celljs/ta-changes`, `@celljs/ta-channels`, `@celljs/ta-computer-use`, `@celljs/ta-cron`, `@celljs/ta-extensions`, `@celljs/ta-games`, `@celljs/ta-glance`, `@celljs/ta-harness`, `@celljs/ta-initiative`, `@celljs/ta-launcher`, `@celljs/ta-manual`, `@celljs/ta-moments`, `@celljs/ta-nearby`, `@celljs/ta-notify`, `@celljs/ta-protocol`, `@celljs/ta-recall`, `@celljs/ta-relay`, `@celljs/ta-rooms`, `@celljs/ta-share`, `@celljs/ta-sync`, `@celljs/ta-sync-cloud`, `@celljs/ta-team`, `@celljs/ta-town`, `@celljs/ta-web`, `@celljs/ta-workspace`)
- Custom model services, by their address and key: Model accounts, API key, Add a custom model service takes the API a service speaks (OpenAI Chat Completions or Responses, Anthropic Messages, Google Gemini), its base URL, a key (none for a server on the computer) and its models, typed or read from the service; saved, they are in the + menu at once. Advanced sets the context window, max output, thinking, pictures and the headers it sends. ta serve keeps each as an entry of pi's `models.json` (`TaAuthServer.saveCustomProvider` and the others); the key and the values of headers never come back to the page. (`@celljs/ta-host`, `@celljs/ta-manual`, `@celljs/ta-protocol`, `@celljs/ta-web`)
- Those invited into a Ta sign in with GitHub with nothing set up: without a GitHub of the owner's, Ta's own OAuth app signs them in by a code (GitHub's device flow, a public client id, no secret). The page of joining and the Ta app's dialog show the code to paste at GitHub; the device code stays in the owner's ta serve, which asks GitHub and verifies the account (`TaHostAccounts.typed`). `TA_GITHUB_DEVICE` turns it off or names an app of one's own; Settings, Access shows GitHub as built in. (`@celljs/ta-host`, `@celljs/ta-protocol`, `@celljs/ta-relay`, `@celljs/ta-team`, `@celljs/ta-web`)

## Patch Changes

- `ui.Game3D` loads models: its context has `GLTFLoader` (glTF 2.0, meshes compressed by meshopt too; not Draco or KTX2) and `SkeletonUtils` (`clone` of a model with bones), each a chunk of its own loaded with Three.js the first time a 3D game starts. `pi.fileUrl(path)` gives a web extension a URL of a file of its own package (a model, a picture, a sound) that loads on a phone and through a relay too, and refuses a path outside the package; `TaWebExtensionInfo.root` says where the package is. The ta-game skill says how to load, place, animate and clone a model, and where one may come from. (`@celljs/ta-extensions`, `@celljs/ta-games`, `@celljs/ta-host`, `@celljs/ta-protocol`, `@celljs/ta-web`, `@celljs/ta`)
- Settings, Access offers no "Sign in with your account" on a page at an address of this machine alone, as the desktop app's: the provider sends no one back there (its redirect address is not registered), and the token lets in anyway. The window of the desktop app opens a redirect of its page to another site in the browser, as it does a link, and no longer goes there itself, with no way back. (`@celljs/ta-web`)
