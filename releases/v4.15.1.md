## Patch Changes

- 3D in replies: Function plot draws surfaces z = f(x, y) and curves in space in 3D, turned by dragging; the new built-in 3D view draws `ta-3d` scenes of shapes, lines, arrows and glTF models of the workspace. Web extensions get the Box icon. (`@celljs/ta-3d`, `@celljs/ta-harness`, `@celljs/ta-plot`, `@celljs/ta-web`, `@celljs/ta`)
- An agent that is not signed in asks how to sign in: CodeBuddy Code picked while signed out offers its ways (iOA, Google / GitHub, WeChat, an enterprise domain) when a message is sent, opens its page in the browser, and the turn goes on once signed in. A web address in a notice of an extension is an Open button. (`@celljs/ta-agents`, `@celljs/ta-web`)
- What the user says while an external agent works reaches it in that turn: CodeBuddy Code gets it through `session/steer` and reads it before it asks its model again, rather than once the whole turn ended. An agent without it still gets it as the next turn, and what waits for that is kept in the session, so that a restart of Ta no longer loses it. (`@celljs/ta-agents`)
- Function plot comes with Ta: functions and curves of replies are drawn as animated plots (`ta-plot` blocks), with params to drag and families of curves; its expressions are parsed, never run. Web extensions get the ChartSpline icon. (`@celljs/ta-harness`, `@celljs/ta-plot`, `@celljs/ta-web`, `@celljs/ta`)
- Ta can be restarted from its web page (Settings, About, and the menu of the account), and the page tells when another build of Ta was installed, with Restart and Later. TaServer.restartServer stops ta serve and starts it again in the same process; TaServerInfo has build, update and restartable. (`@celljs/ta-harness`, `@celljs/ta-host`, `@celljs/ta-protocol`, `@celljs/ta-web`)
