## Minor Changes

- A scheduled task that runs at a time may have a random delay, `jitter` (1m to 12h): each run starts at random within it after the time of its rule, so daily chores run at about a time as a person would, and tasks of the same time spread out. It is set under Random delay in the editor, with `/schedule set <task> --jitter 30m`, or `jitter` of the tool `schedule_task`; the editor shows the next runs as windows. (`@celljs/ta-cron`)

## Patch Changes

- A Ta whose user never picked a dinosaur for the double is given one by its identity (TaDoubleLookUtil.given), the same on every device, so that the people of a room are not all the same green dinosaur. (`@celljs/ta-host`, `@celljs/ta-protocol`)
- ta serve listens before the hosts of the built-in packages start, and Ta Web loads the messages of Traditional Chinese and Japanese only for those who choose them (a `Locale` of @celljs/widget may now have `load()`) (`@celljs/ta-host`, `@celljs/ta-web`)
- The user may give themselves a picture others see in group chats and among friends, instead of the dinosaur of the double, which stays as it is: a photo picked or taken, or one Ta draws (`ta call @celljs/ta-rooms picture <file>`). It is kept end to end in the state of the rooms (TaRoomServer.setPicture, listPictures), and `ui.Face` draws each Ta by its picture when there is one. (`@celljs/ta-host`, `@celljs/ta-protocol`, `@celljs/ta-relay`, `@celljs/ta-rooms`, `@celljs/ta-web`)
- The user's picture is changed in Me (and the menu of the account), as in a messaging app, no more in group chats: a photo, one the double draws, or the dinosaur again. Computers that share one identity (ta-sync) share the picture too, the one changed last winning as the name does. (`@celljs/ta-rooms`, `@celljs/ta-sync`, `@celljs/ta-web`)
- The double draws the user a picture and shows it, and sets it only once the user says it is good. (`@celljs/ta-web`)
