## Minor Changes

- A conversation that stopped at a limit whose error says when it resets goes on by itself then, with a line in it to cancel; the list of changed files above the message box shows what the whole conversation changed too; and a bot of WeChat or WeCom can send what needs the user while they are away from Ta, a reply within 30 minutes going to that conversation. (`@celljs/ta-bots`, `@celljs/ta-changes`, `@celljs/ta-cron`)
- Notifications can be paused for an hour, two, or until 8 AM (Settings → Notifications): meanwhile every conversation is as if muted, so only what needs the user is told, and the pause ends by itself. (`@celljs/ta-notify`)

## Patch Changes

- A scheduled task added without a model keeps the default model of the settings then, so its runs no longer follow whichever model a conversation picked last. (`@celljs/ta-cron`)
- Switching conversations is lighter: the saved conversations come as what changed since the last read (`TaServer.listSavedSessionChanges`) rather than hundreds each time; the avatars no longer look up their parts and lay out the page every frame; folder and home rows of the list draw again only for what they show. (`@celljs/ta-host`, `@celljs/ta-protocol`, `@celljs/ta-rooms`, `@celljs/ta-web`)
