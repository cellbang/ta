## Minor Changes

- A piece of Creator may be read in the voice of Tencent Hunyuan (`voice: "hunyuan"`), more like a person, by the Hy Realtime service set in Ta's voice settings. (`@celljs/ta-creator`)
- Videos of Creator have a look of their own: a pixel dinosaur hosts them, the series opens each piece with its chime and one cover is kept for all, code is typed in a terminal, a phone shows progress and a notification, a summing up is written by hand; drawn by this computer's browser without a window. (`@celljs/ta-creator`)
- Block Earth comes with Ta: @celljs/ta-earth is a built-in package (on by default, off in Settings → Extensions), so a new version of Ta brings its new version, where it was an extension the user installed and updated by hand. (`@celljs/ta-earth`, `@celljs/ta-harness`)

## Patch Changes

- A message sent while the conversation is being compacted waits and goes when the compaction ends (or is stopped), where pi refused it and it had to be sent again by hand. A scheduled task missed because Ta was not running at its time is no longer counted as failed: it says Missed, in grey, and is not in Failed. (`@celljs/ta-cron`, `@celljs/ta-host`)
- The permission gate loads again once installed (`ta install npm:@celljs/ta-permission-gate`): its package named the index of its policy as its extension, which pi refused, so every `ta -p` and `ta` with it installed stopped at once. A mistake in the command line of Ta's own commands (`ta serve`, `relay`, `pair`, `gateway`, `call`, `exec-server`) is said in a line with where the help is, not as a stack of Node.js, and a port that is no port (`--port abc`) is refused rather than taken as another one. (`@celljs/ta-harness`, `@celljs/ta-permission-gate`, `@celljs/ta`)
- While a conversation is being compacted, the button of the message box stops it (Esc too), as it stops a run: pi's abort ends the compaction, where before the box had only a grey Send and the compaction could not be stopped. (`@celljs/ta-web`)
