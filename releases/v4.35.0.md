## Minor Changes

- Extensions: three levels of access. A package says what its web extension needs, `"access": "browser" | "app" | "full"` in `pi` (`full` when it does not say), and gets the API only as far as that reaches. Your own extensions run as they are; another's (installed, opened from a link or the market) is allowed as you install or open it, and asked again once it changes: an update runs only after you allow the new version. One you did not allow waits in the list of extensions, marked, with Allow to run. Those that ran before keep running. (`@celljs/ta-extensions`, `@celljs/ta-host`, `@celljs/ta-protocol`, `@celljs/ta-web`)
- Another's extension below full access runs in a sandbox whose UI is copied into the page (remote UI): one runtime for the extension however many places show it, its elements drawn in Ta's own page so that its theme, font sizes and layout are Ta's, Ta's components (Markdown, Switch, Dialog, icons…) drawn for it by the page, its styles kept to its own place, links opened through `openLink`, and no script, frame or `javascript:` address reaching the page. What it may use is one entry each in `WEB_API_SPEC` (its level and how it crosses), from which the page cuts the API, the sandbox makes its `pi` and the hooks it uses run in the page (`useDevice`, `usePages`…), so that a member added to the API needs no other code. It keeps a `localStorage` with its data. Settings → Extensions say how far extensions others made are trusted (web page only, ask each version, trust fully; the owner's alone) and, on this device, whether to run them apart, keep their local data and let them use Ta's components. A device that cannot run a sandbox says so where the extension is listed, never running it in the page instead. (`@celljs/ta-extensions`, `@celljs/ta-host`, `@celljs/ta-protocol`, `@celljs/ta-web`)
- Extensions: another's extension allowed less than full access runs in a sandboxed frame of its own, never in Ta's page. It reaches Ta only through the part of the API its level gives, each call checked by the page; its pages, widgets and cards show in frames that follow Ta's look. One that asks only for what a web page has is no longer asked for, installed or updated. (`@celljs/ta-extensions`, `@celljs/ta-host`, `@celljs/ta-web`)
- Extensions others made can be turned off altogether (Settings → Extensions: off, web only, ask each version, full): off, none of them runs and none asks, and the list says so on each. With people let in, changing this and giving one of them full access need a new action, `extensions.trust` ("decide how far others' extensions reach"), which only admins have of the preset roles; one without it is told and may ask for it, and the record marks it as risky. (`@celljs/ta-extensions`, `@celljs/ta-host`, `@celljs/ta-protocol`, `@celljs/ta-team`, `@celljs/ta-web`)
- A page of an extension can be installed as an app of the computer, in Ta Desktop: hold it in Quick open and pick Install as app. It gets a window, a name and an icon of its own (the tile of the launcher, drawn large), and opens from Launchpad, Spotlight and the Dock on macOS (a small app in ~/Applications/Ta Apps), the Start menu on Windows (its own button in the taskbar) and the menu of applications on Linux, starting Ta first when it is not running. The window shows that page alone, with the same extension, data and access as in Ta. Remove from apps in the same menu, or in Settings, Extensions, where Install pages as apps turns it off for this device (those installed still open). Extensions get `pi.ui.apps` (app access; a sandbox installs only pages of its own), and every page its `tint`, the colour of its tile. (`@celljs/ta-launcher`, `@celljs/ta-web`)
- Moments: make your own version of a friend's post. A post may hold its recipe (how to make it again) and a game, played right in the post as a game of a reply is, the game staying on its author's computer as the pictures do. Make my version opens a conversation where Ta makes yours from the recipe and the game, and its draft says whose post it came from; the post shows "Made from …", the one it came from shows who made their version, and its author is told. The daily brief, picking friends' posts for you, may draft a comment or what of yours a post could become, each sent or made only when you tap it. (`@celljs/ta-moments`)

## Patch Changes

- A web extension that stops ends what it writes down with `ui.voice.transcribe` and lets go of `ui.keepAwake`, and opens neither once stopped; the cursor of app use reads a touch from the page's `data-touch`. (`@celljs/ta-app-use`, `@celljs/ta-extensions`, `@celljs/ta-web`)
- An agent the user had Ta make can be invited to group chats with friends, as one they made by hand: every list of the user's agents goes by one rule, and `create_agent` takes `keep` for an agent the user asked for. (`@celljs/ta-channels`, `@celljs/ta-rooms`, `@celljs/ta-town`)
- What Ta wrote by hand, in Cell: `FileUtil` writes files whole (a temporary file, then a rename); `ApplicationLifecycle.onReady` runs once the server answers, so the first request does not wait for work that can; `WebSocketUpgrades` routes the upgrade requests of a server by path, with one listener; `RpcWebSocketClient` reconnects, waits for the connection, resends what is safe to send twice and checks a stalled connection; `RpcPushChannel` batches what the server pushes to a client and bounds a slow one. `ta serve` uses them all, and starts to its first page about 10 ms sooner. (`@celljs/ta-client`, `@celljs/ta-host`)
- The same work asked twice is not done twice: when a request is much like one of the last 24 hours in another conversation that is at it now or just did it (asked there by the user or by a package, as Make of Creator), Ta links it and asks the user whether to wait for it and use what it makes or do it here too, or uses what came of it, unless told plainly to do it again. It no longer depends on Keep being on. Creator asks Ta to make a piece with its title only to see, its id in the context, so that it is told from a request in chat for the same piece. (`@celljs/ta-creator`, `@celljs/ta-recall`)
- A scheduled run counts only the time the computer is awake against its timeout: one that starts in a short wake of a sleeping computer is no longer stopped as too long once it wakes. (`@celljs/ta-cron`)
- A chat of two is the two of you: agents are not invited into it; @ any agent of yours there and it answers you alone. Its + and info start a group chat with the friend, people or agents added. A group chat started from a chat of two offers to bring that chat in, as chat history in one card, and to have an agent of yours look at it. (`@celljs/ta-feedback`, `@celljs/ta-relay`, `@celljs/ta-rooms`)
- ta serve no longer loads pi while nobody uses it: the host of a package is told the directory of its package (`TaExtensionHost.root`), so the mouths and moves of a video call find their files without listing every package, and Initiative counts its numbers once a conversation runs. Idle, ta serve takes about 52 MB instead of 96 MB. What a conversation asks the user to decide (`TaAskUtil`) is in ask-protocol of @celljs/ta-protocol. (`@celljs/ta-feedback`, `@celljs/ta-glance`, `@celljs/ta-goals`, `@celljs/ta-host`, `@celljs/ta-initiative`, `@celljs/ta-lips`, `@celljs/ta-moves`, `@celljs/ta-notify`, `@celljs/ta-protocol`, `@celljs/ta-secops`)
- A meeting being written down keeps the device awake (the screen of a phone no longer locks under it, Ta Desktop keeps the display on and does not restart mid-meeting), and listening that breaks off (the service closed, the network went, the page was hidden) reconnects by itself, at once as the page shows again; saving the end is tried again when it fails. Web extensions get `pi.ui.keepAwake()`, held by calls and meetings alike, so one ending does not let the screen lock under another; a remote desktop being watched and what one nearby shows on this screen keep it on too. (`@celljs/ta-meeting`, `@celljs/ta-nearby`, `@celljs/ta-screen-share`, `@celljs/ta-web`)
- A closing curly quote inside a string of a card ends it only when a curly quote opened it: `显示“正在压缩”，等它压完` keeps its words, and the buttons of a card are no longer lost to it. (`@celljs/ta-protocol`)
- A link a sandboxed extension did not handle opens through the guard of `openLink` and the extension's access, as the design says, rather than straight to `pi.openLink`: a sandbox could open `ta://` and other links that are not of the web by clicking or sending one. (`@celljs/ta-web`)
- The package carries its `Dockerfile`, so a deployment follows the releases on its own: `deploy/compose/update.sh npm` (hourly in cron) builds the latest release when it is newer than the one running, and the gateway moves the sandboxes to it when they are idle. (`@celljs/ta`)
